# ☕ Em Família Coffee Shop

Site moderno e minimalista desenvolvido para uma cafeteria premium chamada **Em Família Coffee Shop**.

O projeto foi criado com foco em:
- elegância
- experiência visual
- responsividade
- acessibilidade
- identidade minimalista em preto e branco

---

# ✨ Visão Geral

O site apresenta uma experiência sofisticada para cafeterias modernas, destacando:

- cafés artesanais
- sobremesas
- ambiente aconchegante
- espaço para trabalho com notebook
- serviços da cafeteria
- acessibilidade
- contato rápido via WhatsApp
